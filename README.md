## Задание 2: Автотесты для API Stellar Burgers

### Что тестируем

- Создание пользователя:
  - уникальный пользователь
  - повторная регистрация уже созданного пользователя
  - отсутствие обязательного поля
- Логин пользователя:
  - успешный вход существующего пользователя
  - вход с неверными логином/паролем
- Создание заказа:
  - с авторизацией
  - без авторизации
  - с валидными ингредиентами
  - без ингредиентов
  - с неверным хешем ингредиентов

### Стек

- `pytest`
- `requests`
- `allure-pytest`

### Структура проекта

- `stellar_burgers_api` — обертка для HTTP-запросов к API
- `tests` — автотесты и фикстуры (`conftest.py`)

### Подготовка окружения

> `$ pip install -r requirements.txt`

### Запуск тестов

> `$ python -m pytest -s -q --alluredir=allure_results`

### Отчет Allure

> `$ allure serve allure_results`
